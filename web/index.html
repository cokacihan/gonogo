Which F´ requirements are backed by passing tests?

Every lamp is a component of NASA's F´ flight-software framework. It lights green only when each test that cites a requirement passed in a real CI run. The graph, the verdicts and the Cypher behind them run on Relate, compiled to WebAssembly, in this tab.

What must I re-run after a change?

List the F´ files you changed, one per line, paths from the repository root. A changed component re-runs its own unit tests; a changed port-type definition re-runs the tests of every component that uses it. Topology changes are flagged for integration review only.

Each release was imported into its own Relate store and compared side by side. Bars count requirements; the line is the share cited by a test of their own component.
